# Loophole

The Flutter app, for the Ultrahuman Ring AIR, with no account or server. This version hasn't run on a phone or a ring yet. It is not affiliated with or endorsed by Ultrahuman.

What works, what is tested and what isn't: see [What works and is tested](../README.md#what-works-and-is-tested). Sleep tracking is built and has unit tests, but it is not validated on a real night.
